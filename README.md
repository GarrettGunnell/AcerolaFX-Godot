# AcerolaFX (Godot)

by Acerola

## Overview

AcerolaFX is a suite of shaders for the Godot game engine. More specifically, AcerolaFX is a suite of post processing compositor effects. At this point in time the scripts in this repo are **not to be used** in production as they are all experimental. The shader code is optimized but the scripts themselves are not so for now please only use these shader effects to learn from and experiment with. Do not make games with them. Do not release software using them.

I'll make a video when the scripts are usable in production but that'll probably be awhile as right now I'm just having fun playing with toys.
